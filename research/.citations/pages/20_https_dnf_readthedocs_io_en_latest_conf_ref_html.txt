# DNF Configuration Reference 
## [main] Options 
List of paths that are likely to cause problems when their contents drift with respect to <code>/usr</code>, e.g. <code>/etc/pam.d/*</code>. If a transient transaction would modify these paths, DNF aborts the operation and prints an error. Supports globs. Defaults to <code>glob:/etc/dnf/usr-drift-protected-paths.d/*.conf</code>.
