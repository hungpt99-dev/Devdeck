#

[![Ask DeepWiki](https://camo.githubusercontent.com/b876cdb51d268b8a0cfce1b2864a90ee8f7a16ac8d39c439d6367495a3b63dd9/68747470733a2f2f6465657077696b692e636f6d2f62616467652e737667)](https://deepwiki.com/aquaproj/aqua) [Document](https://aquaproj.github.io/) | [Contributing](/aquaproj/aqua/blob/main/CONTRIBUTING.md) | [Logo](/aquaproj/aqua/blob/main/logo) | [Scorecard](https://securityscorecards.dev/viewer/?uri=github.com/aquaproj/aqua)

Declarative CLI Version Manager written in Go.

- Switch tool versions per project
- Unify tool versions and how to install in your teams and CI
- Continuous update by Renovate
- Lazy Install
- Ecosystem by Registry
- Secure
- Easy to use
