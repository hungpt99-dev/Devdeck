# ADR 0003 — Internationalization

Status: Accepted (2026-11-22).

## Decision

Project Fluent (`fluent` 0.17, `.ftl`) owns messages, plurals, variables and gender; ICU4X 2.4 handles locale identifiers, canonicalization, and (in later phases) dates, times, numbers, units, relative time, collation and segmentation. Compare with ICU MessageFormat: rejected for message files because Fluent has better Rust tooling, separation of translation from code, and first-class plural/variable syntax.

English is the source language; Vietnamese ships in the first public release. `sys-locale` detects the OS locale on first run; the user can override it at runtime without restart. Fallback chain: `vi-VN → vi → en`. Typed message keys are generated from `locales/en/*.ftl` by `crates/i18n/build.rs`, so wrong keys fail to compile. `cargo run -p devdeck-xtask -- i18n-lint` enforces en/vi key parity in CI.

Canonical tool names, descriptions and parameters stay English and stable for MCP/agents; localization is a display layer. Logs and audit entries remain machine-readable. Search is diacritic-insensitive with NFD normalization plus explicit đ/Đ mapping.

## Risks

- Fluent inserts Unicode bidi isolate marks around variables by default; the host disables isolating for plain UI labels and will add explicit isolation for RTL text.
- RTL layout mirroring and CJK/IME stress tests are Phase 7 work; upstream Iced has no full bidi layout engine yet.
- Language packs as extensions depend on the extension host landing in Phase 2; en and vi remain built in.
